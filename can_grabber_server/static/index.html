Why this stack

Simple Python-side editing path

  • You can now open a single DBC directly from the page. It is copied into persistent storage first.
  • `cantools` loads the DBC, exposes messages and signals, and can write the edited file back out.
  • Imported DBC files are copied into a persistent machine-local `.can-grabber/dbc` folder.
  • The architecture stays small: one app-home folder, one backend manager, one frontend page.

How this works

  • The scan checks `PATH`, common `InfluxData` install folders, Scoop locations, and shallow portable folders.
  • If auto-detection misses, paste the `influxd.exe` or `influxdb3.exe` path and save it manually.
  • The start action launches the selected binary and writes output to the local runtime log.

Firmware target

Use the integrated server process

  • Multipart uploads are accepted at `/edit` and `/upload`.
  • Raw stream uploads are accepted at `/edit-chunked` and `/upload-chunked`.
  • The original upload server UI remains available under `/upload-server/ui`.
  • Saved files use the upload server directory configured by `CAN_UPLOAD_DIR`.
